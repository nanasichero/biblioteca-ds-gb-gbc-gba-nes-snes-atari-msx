Central de Repositório: Banco de 7.450+ Jogos

Hospede seu banco de dados global de ecossistemas do Nintendo DS diretamente na nuvem de forma gratuita.

🚀 Como colocar este Hub no ar via GitHub Pages:

  1. Crie uma conta gratuita no site oficial do GitHub se ainda não tiver.
  2. Crie um repositório público chamado biblioteca-ds.
  3. Suba este arquivo renomeado exatamente como index.html para a raiz do repositório.
  4. Suba o arquivo Banco_de_Dados_7000_Jogos.json para a mesma pasta.
  5. Vá nas configurações (Settings) do repositório, clique na aba Pages, selecione a branch main / root e salve.
  6. Pronto! O GitHub gerará um link público para você acessar sua biblioteca de qualquer lugar do mundo pelo celular ou PC.
